# 问题一：按截图约束求解的混合整数线性规划

本版本严格采用所附 `input/constraints.png` 中的目标和约束。每天划分144个10分钟时段，使用附件1的电价、负载和光伏预测功率，求解当天最低购电费用。

## 运行

推荐Python 3.11或更新版本，已在Python 3.13.9运行验证。仅依赖NumPy、SciPy和openpyxl；SciPy内置HiGHS求解器，不需要商业求解器。

在仓库根目录执行：

```bash
python -m pip install -r question1/requirements.txt
python question1/q1.py
```

若终端当前已在question1目录，则运行 `python q1.py`。macOS按本机配置使用python或python3命令。输入、模板和结果默认相对于脚本所在目录解析。

可选参数：

```bash
python question1/q1.py --input "question1/input/附件1.xlsx" --template "question1/input/result1模板.xlsx" --output "question1/results"
```

自定义相对路径相对于终端当前目录。重复运行覆盖所选结果目录的result1.xlsx、q1_detail.csv、q1_summary.json，源数据和源模板不变。

## 与截图逐项对应的模型

令Δt=1/6小时，Pmax=5000 kW。附件中的L和G为功率kW；代码先转换为每时段电量 `load=L*Δt`、`pv=G*Δt`。价格p的单位为元/kWh。

| 符号 | 代码变量 | 含义及单位 |
|---|---|---|
| g_t | g | 外网购电量，kWh |
| c_t | c | 送入储能的微网侧电量，kWh |
| d_t | d | 储能送出的微网侧电量，kWh |
| r_t | r | 弃光量，kWh，仅来自光伏 |
| S_t | s | 电池内部储电量，kWh |
| u_t | u | 二元开关；1允许充电，0允许放电 |

目标函数严格为：

```text
min Z = Σ(t=1..144) p_t g_t
```

全部约束：

```text
g_t + G_t Δt - r_t + d_t = L_t Δt + c_t
g_t ≥ 0
0 ≤ r_t ≤ G_t Δt
0 ≤ c_t ≤ Pmax Δt u_t
0 ≤ d_t ≤ Pmax Δt (1-u_t)
S_t = S_(t-1) + 0.9 c_t - d_t/0.9
1200 ≤ S_t ≤ 10800                 t=0,...,144
u_t ∈ {0,1}
S_0 = 6000
S_144 = S_0
```

程序使用 `scipy.optimize.milp` 直接求解，包含144个二元变量；不做LP充放电消除后处理。目标中没有附加平局费用、日末储电奖励或弃光罚金；约束中没有额外的放电不超过负载限制，也没有允许已购外网电弃用的变量。r的上限只取光伏电量，不取“购电加光伏”。

购电、光伏均可直接供负载，也可给电池充电；容量仅限制当时电池中的电量。u是“允许方向”开关，u=1并不要求必须充电；如果充放电都为0，u取0或1均可行。

## 时间与效率口径

沿用此前对附件的时段解释：00:10记录对应00:00—00:10，24:00记录对应23:50—24:00，输入功率按区间平均值使用。原模板时间标签整体偏移一个时段，仅在输出副本修正，源模板不修改。

截图已明确充放电效率分别为0.9，因此往返效率为0.81。c、d为微网侧电量，S为电池内部储电量，三者不能直接混用。每10分钟最大充、放电量为5000/6=833.333333... kWh。

## 结果与验证

最优购电费用 **35126.948589289634元**，全天购电 **59482.69899835391 kWh**，充电 **20740.666131687245 kWh**，放电 **16799.939566666668 kWh**，弃光 **0 kWh**。日初日末均为6000 kWh，全天储电范围1200—10800 kWh。

无储能费用为48052.046590846665元，节省12925.09800155703元，约26.8981%。HiGHS报告最优间隙0，最优下界与目标值相同。程序每次运行都会检查能量平衡、SOC递推、容量、功率、弃光上限、二元开关和初末储电约束。

与旧模型相比，本版本改变了弃电范围、删除附加限制和微小平局项，但附件1的最优费用仍相同。旧最优轨迹本来就没有弃电，因此不能因为结果相同而认为两个模型的约束完全相同。

Excel保留题目要求的两张表，另附结果汇总和口径说明。电量显示4位小数、费用2位小数，底层数值保留计算精度；总计直接保存数值。不同求解器版本可能返回不同的等价最优安排，应按约束满足情况和最优费用比较。
